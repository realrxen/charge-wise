# Chargewise · 特斯拉充电成本对比

仅比较家庭充电桩与第三方公共快充，不含超充权益。纯静态 HTML / CSS / ES Modules，无需安装依赖。

**在线访问与分享：** https://realrxen.github.io/charge-wise/

GitHub Actions 在每次推送到 `main` 后运行计算测试并发布 `dist/` 到 GitHub Pages，也可在 Actions 中手动运行。页面参数仅保存在访问者自己的浏览器中，分享链接不会带上你的本地参数。

**直接使用：** 用浏览器打开本目录的 `chargewise.html`，无需服务器，也不依赖网络。该单文件由 `npm run build` 从 `dist/` 源代码生成，修改源码后重新生成即可。

**开发预览：**

```sh
git clone https://github.com/realrxen/charge-wise.git
cd charge-wise
npm run dev
```

打开 http://localhost:4173 。运行计算引擎测试：`npm test`。

支持里程完成比例、自然日租期统计、家充线路安装、退租拆除及残值、24 小时独立电费与服务费、实际平均功率与固定 50 度单次电量、停车费与额外时间、现金 / 经济口径、成本构成图、里程占比、分时电价、回本外推、四种敏感性分析，以及费用和电价表 CSV 导出。参数仅保存在当前浏览器的 localStorage。

两张方案对比卡片分别列出费用构成、计费公式、现金支出和经济成本；当前所选口径的合计行高亮，与卡片大金额一致。

参数设置位于结果上方。家庭电价默认 0.4 元/度；公共费用使用上方“公共快充”参数区填写的综合计算单价，默认 0.7 元/度（含电费与服务费），每次固定按 50 度估算，末次按剩余需求计费。24 小时分时表仅供参考，修改此表只更新电价图和参考均价，不影响费用。不设置充电时间偏好，不进行充电排期；旧版本保存的时间窗口、模式、允许小时及电量权重会在读取时移除，新版读取旧参数时，将旧默认家庭电价 0.45 更新为 0.4，未手动修改的分时表更新为截图价格，每次充电量统一为 50 度；其他自定义费用参数保留。

## 计算口径

电价表支持逐行收起、按时间范围批量收起和全部展开；连续收起的小时合并为一条可展开的摘要。收起偏好独立保存在浏览器，不改动价格或任何计算；恢复默认时全部展开。“价格来源”只区分默认参考价、你提供的综合价和你设置的价格，无需另行确认。

- 租期首尾包含；周六、周日各使用周末合计里程的一半；不处理调休和法定节假日。
- 百公里充电量已包含损耗。使用设置的实际平均功率，不模拟充电曲线或温度衰减。
- 公共充电费 = 总需求电量 × 手动填写的公共综合单价。默认 0.7 元/度，已含电费与服务费，不再叠加分时表中的服务费。费用明细将公共充电费合并展示，不对手填单价臆造电费 / 服务费拆分。
- 公共充电次数 = 总需求电量 ÷ 固定 50 度向上取整，末次只计剩余电量。每次的停车费分别计算免费额度；末次停车时长按剩余电量及功率计算。零电量时不产生充电次数、停车费或时间成本。
- 分时参考表按用户提供的新电途截图录入，电费与服务费均有明确数值；24 小时等权参考均价为 0.9425 元/度，只供参考，不参与费用比较、回本或敏感性分析。截图末段 22:00–23:59 按 22:00–24:00 覆盖当天最后一分钟。
- 步行按 80 米 / 分钟，往返单程距离 × 2。时间成本只计往返与其他额外耗时，默认充电等待可与办公重叠。停车占用 = 充电 + 步行 + 其他额外耗时；超时按分钟折算。
- 家充线路前 40 米免费；超长安装费 = max(总线路长度 − 40, 0) × 超出部分单价，其他额外安装费单独叠加。默认线路 40 米、超长单价 25 元/米；超过 40 米但未填单价时暂停费用比较。
- 充电桩可拆卸保留。默认勾选退租拆除，拆除费 = 200 + 5 × 总线路长度（米）；取消勾选则为 0。勾选拆除时，租期不超过一年自动填入 800 元残值、超过一年填入 400 元；按首尾计天，以起租日周年的前一天为一年内最后一天，闰日周年按次年 2 月末。残值按后续继续使用、节省再次购买充电桩费用估算。自动模式随租期重算，手动填写后保留手动值，可点击“恢复自动估算”。不拆除时自动残值默认为 0 元，但仍可手动填写转让等期末价值；手动残值不随租期或拆除选项变化。拆除费计入租期现金和经济成本、成本图表、回本及敏感性分析、明细与 CSV，前期投入仅含设备及安装。
- 经济成本 = 实际现金支出 + 时间价值 − 残值，保留或转让充电桩的预估残值不视作现金退款；不包含后续搬运、重新安装与维修费用，不拆除时默认 0 元，可手动填写。
- 回本用当前公共单位综合成本及当前租期残值固定线性外推，不约束当前租期，不预测价格；跨年后残值可能改变，交点不保证此后一直保持成本更低。敏感性分析随需求电量、手填公共单价、租期和残值重算费用。

默认预测：111 天，79 个工作日、32 个周末日，8,750 公里、1,750 度。预计公共充电 35 次，计算单价 0.7 元/度，公共现金 1,225 元、经济成本 1,487.50 元；家充现金 2,599 元、经济成本 1,799 元（家庭电价 0.4 元/度、默认线路 40 米、超长单价 25 元/米、超长安装费 0 元、退租拆除费 400 元、残值 800 元）。
