# Chargewise · 特斯拉充电成本对比

仅比较家庭充电桩与第三方公共快充，不含超充权益。纯静态 HTML / CSS / ES Modules，无需安装依赖。

**在线访问与分享：** https://realrxen.github.io/charge-wise/

GitHub Actions 在每次推送到 `main` 后运行计算测试并发布 `dist/` 到 GitHub Pages，也可在 Actions 中手动运行。页面参数仅保存在访问者自己的浏览器中，分享链接不会带上你的本地参数。

**直接使用：** 用浏览器打开本目录的 `chargewise.html`，无需服务器，也不依赖网络。该单文件由 `npm run build` 从 `dist/` 源代码生成，修改源码后重新生成即可。

**开发预览：**

```sh
git clone https://github.com/realrxen/charge-wise.git
cd charge-wise
npm run dev
```

打开 http://localhost:4173 。运行计算引擎测试：`npm test`。

支持里程完成比例、自然日租期统计、家充安装及残值、24 小时独立电费与服务费、精确到分钟的多个可用窗口、逐次低价排期、自定义小时电量权重、功率与单次电量、停车费与额外时间、现金 / 经济口径、成本构成图、里程占比、分时用电、回本外推、四种敏感性分析，以及费用和逐次充电安排 CSV 导出。参数仅保存在当前浏览器的 localStorage。

参数设置位于结果上方；允许充电窗口按行纵向排列。电费与服务费统一在下方 24 小时电价表中修改，上方“充电时段单价引用”、加权均价、费用明细、图表与推荐结论实时引用同一份价格数据，无需再次应用。查看多个小时且价格不一致时显示最低–最高单价，实际费用仍逐小时按实际电量计费，不使用该区间的算术平均价。允许充电时间与分时价格分别设置。

## 计算口径

电价表支持逐行收起、按时间范围批量收起和全部展开；连续收起的小时合并为一条可展开的摘要。收起偏好独立保存在浏览器，不改动价格、允许充电开关、电量占比或任何计算；恢复默认时全部展开。“价格来源”只区分默认参考价、你提供的综合价和你设置的价格，无需另行确认。

- 租期首尾包含；周六、周日各使用周末合计里程的一半；不处理调休和法定节假日。
- 百公里充电量已包含损耗。使用设置的实际平均功率，不模拟充电曲线或温度衰减。
- 每日可用窗口重叠时合并，禁用小时剔除。智能策略逐次选取最低电费 + 服务费的连续可用片段，已占用片段不会重复。只有所有剩余片段均容纳不了单次目标时才缩减单次电量。不保证含停车与时间成本的全局最优。
- 自定义模式按有效小时权重归一化分配，容量不足提示不可行；不连续到站分别计次。
- 电价按实际小时电量计费，末分钟按实际部分电量计入。15:00–20:00 综合价是用户提供；电费与服务费拆分暂估，其余电价均为待确认默认值。
- 步行按 80 米 / 分钟，往返单程距离 × 2。时间成本只计往返与其他额外耗时，默认充电等待可与办公重叠。停车占用 = 充电 + 步行 + 其他额外耗时；超时按分钟折算。
- 经济成本 = 实际现金支出 + 时间价值 − 残值，残值不视作现金退款。
- 回本用当前实际公共单位综合成本线性外推，不约束当前租期，不预测价格。敏感性分析重算真实情景，不能完成充电的点不绘制公共成本。

默认预测：111 天，79 个工作日、32 个周末日，8,750 公里、1,750 度。智能公共计划 44 次，综合均价 0.750 元 / 度；公共现金 1,312.50 元、经济成本 1,642.50 元，家充现金及经济成本均为 2,286.50 元（默认残值为 0）。
